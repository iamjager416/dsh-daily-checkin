# 每日签到

每天自动帮你签到三款游戏，签完把结果推到 QQ。

## 支持

- **库街区**：鸣潮、战双（游戏签到 + 社区签到 + 库洛币余额）
- **森空岛**：明日方舟、终末地
- **塔吉多**：异环（社区 + 游戏角色）

## 开始用

1. 打开 **设置 → 每日签到**。
2. 勾选平台，填手机号 → 点「发送验证码」→ 填验证码 → 点「绑定」。
3. 设好每天运行时间（默认 22:05），保存。

之后每天到点自动签到。错过当天（电脑关机/DSH 没开）会在下次启动后补跑，同一天不会重复跑。

想立刻跑一次或看结果，直接跟助手说「跑一次签到」「看签到报告」就行。

## QQ 推送

在同一个面板打开「签到完成后主动推送到 QQ」，填机器人 AppID、AppSecret 和接收人的 openid，保存。用「立即签到一次」可以验证推送是否通。

## 你需要知道的

- 登录态只存在本机 `~/.dsh/checkin/credentials.json`，不写进插件配置，也不进会话记录；签到请求只发往各游戏官方接口。
- 短信验证码 5 分钟有效，同一号码 60 秒冷却。
- 运行时间跟随本机时区，改系统时区它跟着变。
- 异环的登录态每次签到后会自动轮换并写回，不用手动处理。
- 森空岛偶尔会要求人机验证，这时发不出验证码，过几分钟再点一次。
